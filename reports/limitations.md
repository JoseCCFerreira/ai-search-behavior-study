# Limitations

- Google Trends provides relative interest values, not absolute search volume.
- Similarweb-style traffic data may require paid exports or manual collection.
- Browser and search market share are not direct measures of user intent.
- AI tool usage can occur via apps, APIs, browsers, and integrations that are hard to measure.
- Correlation does not imply causation.
- Synthetic demo data should not be used to draw real-world conclusions.
