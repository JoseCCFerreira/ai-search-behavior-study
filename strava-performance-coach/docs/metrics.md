# Performance Metrics

This document explains the performance metrics used in Strava Performance Coach.

## Overview

The system calculates several key metrics to analyze your training:

- **Performance Score**: Overall activity quality (0-100)
- **Training Load**: Cumulative training stress
- **Fatigue Score**: Accumulated fatigue level
- **Readiness Score**: Ability to train today
- **Trend Analysis**: Performance improvements over time
