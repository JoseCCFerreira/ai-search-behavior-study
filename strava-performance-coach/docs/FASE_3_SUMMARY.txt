
### 📈 Queries Prontas para Usar

**Performance Semanal**
```sql
SELECT
    d.summary_date,
    d.daily_score,
    d.total_distance_km,
    d.total_moving_time_minutes,
    d.num_activities
FROM daily_summary d
WHERE d.summary_date >= CURRENT_DATE - INTERVAL 7 DAY
ORDER BY d.summary_date DESC;
```

**Atividades por Tipo (Últimas 2 Semanas)**
```sql
SELECT
    activity_type,
    COUNT(*) as num_activities,
    SUM(distance_km) as total_km,
    AVG(average_speed_kmh) as avg_speed,
    AVG(average_heartrate) as avg_hr
FROM stg_activities
WHERE activity_date >= CURRENT_DATE - INTERVAL 14 DAY
GROUP BY activity_type
ORDER BY total_km DESC;
```

**Métricas de Performance**
```sql
SELECT
    a.activity_date,
    a.activity_type,
    a.distance_km,
    a.average_pace_min_km,
    m.performance_score,
    m.intensity_level,
    m.training_load
FROM stg_activities a
LEFT JOIN fct_activity_metrics m ON a.activity_id = m.activity_id
ORDER BY a.activity_date DESC
LIMIT 20;
```
