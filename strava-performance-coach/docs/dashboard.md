# Dashboard Guide

This document describes the Streamlit dashboard and its features.

## Overview

The dashboard provides interactive visualizations of your performance data.

### Pages

1. **Overview**: High-level summary and KPIs
2. **Activities**: Detailed activity listing and filtering
3. **Performance**: Performance trends and analysis
4. **Training Load**: Training load and intensity
5. **Fatigue & Recovery**: Fatigue levels and recovery status
6. **Coach**: Personalized coaching recommendations
7. **Machine Learning**: Advanced analysis and predictions

*Full documentation will be completed in Phase 9.*
