1. Visão geral

O Strava Performance Coach é uma app local em Streamlit para importar atividades exportadas do Strava, guardar os dados numa base DuckDB dedicada e analisar desempenho, evolução, recordes, mapas GPS e tendências.

A app atual funciona sem ligação direta ao Strava. Não existe botão de autenticação OAuth. O fluxo é simples: descarregas os ficheiros, fazes upload na app, a base é atualizada apenas com atividades novas e depois analisas tudo no dashboard.

Entrada de dadosExport completo .zip ou atividades individuais .gpx, .fit, .tcx, .gz e .git.
AnáliseKPIs, estatística, tendências, previsões, mapas, heatmaps, recordes e detalhe por atividade.
ArmazenamentoBase DuckDB local, otimizada com VACUUM/CHECKPOINT após imports.

3. Instalação

Na raiz do projeto:

cd /Users/carlosferreira/Projecto/strava-performance-coach

3.1 Criar ambiente virtual

python3 -m venv .venv
source .venv/bin/activate

3.2 Instalar dependências

Se existir requirements.txt:

pip install -r requirements.txt

Se usares outro gestor do projeto, instala as dependências equivalentes para Streamlit, Pandas, Plotly e DuckDB.

3.3 Dependência opcional para performance

O Streamlit pode recomendar watchdog para melhorar o reload local:

pip install watchdog

4. Configuração

A configuração principal vem de config/settings.py e do ficheiro .env, quando existir.

Exemplo mínimo:

DUCKDB_PATH=database/strava_coach.duckdb
RAW_DATA_DIR=data/raw
Não coloques .env, tokens, exports Strava, ficheiros GPX/FIT/TCX nem bases DuckDB no Git. Estes dados são pessoais.

5. Execução da app

Executa a app na pasta do projeto:

streamlit run app/streamlit_app.py --server.port 8501

Depois abre:

http://localhost:8501

Modo headless, útil quando queres deixar a app a correr sem abrir browser automaticamente:

streamlit run app/streamlit_app.py --server.headless true --server.port 8501 --browser.gatherUsageStats false

Para parar a app, usa Ctrl+C no terminal onde o Streamlit está a correr.

6. Workflow recomendado

  1. Exporta novas atividades do Strava ou descarrega ficheiros individuais.
  2. Abre a app em http://localhost:8501.
  3. Na sidebar, faz upload do ficheiro.
  4. Mantém Import only new activities ativo.
  5. Espera pela mensagem final de import.
  6. Usa os filtros de ano, mês, intervalo de datas e tipo de atividade.
  7. Começa pelo Training Hub e depois analisa General Results, Activity Deep Dive, Records & Forecasts e mapas.
Para uso diário, basta importar uma vez por dia. A app verifica atividades já existentes e ignora duplicados quando Import only new activities está ativo.

7. Upload e atualização de atividades

Na sidebar, usa Upload Activities.

  1. Clica em Browse files.
  2. Seleciona .zip, .gpx, .fit, .tcx, .gz ou .git.
  3. Se for atividade individual, escolhe o tipo: Run, Ride, Walk, Hike, Swim ou Workout.
  4. Deixa Import only new activities ativo para atualizar só novidades.
  5. Clica em Import Uploaded File.

Resumo típico:

loaded=1, skipped=0, failed=0, streams=3256, metrics=711, recommendations=11
CampoSignificado
loadedAtividades novas importadas.
skippedAtividades já existentes ignoradas.
failedAtividades que falharam.
streamsPontos GPS/telemetria importados.
metricsMétricas recalculadas.
recommendationsRecomendações geradas.

O ficheiro enviado é temporário: a app importa, atualiza a base, otimiza e remove o ficheiro de upload.

8. Base de dados dedicada

A app usa DuckDB para guardar atividades, streams GPS, métricas e recomendações. Por defeito:

database/strava_coach.duckdb

Para usar outra base dedicada, define:

DUCKDB_PATH=database/minha_base_atividades.duckdb

A app aplica o schema automaticamente ao arrancar. Depois de imports, corre otimização com VACUUM e CHECKPOINT.

10. Training Hub

A página Training Hub mistura ideias úteis de plataformas como Strava e Garmin Connect, adaptadas aos teus dados locais e sem ligação direta a serviços externos.

Estilo StravaFeed de atividades recentes, cartão por atividade, métricas rápidas, recordes e zonas favoritas.
Estilo GarminEstado de treino, carga aguda vs linha de base, intensidade, objetivos mensais e indicadores de recuperação.
Modo localTudo é calculado a partir da base DuckDB, usando os ficheiros que importaste.

Inclui:

  • cartões de estado de treino, últimos 7 dias e últimos 30 dias;
  • objetivos mensais de distância, tempo e elevação comparados com a tua linha de base;
  • feed das atividades recentes com distância, tempo, pace, velocidade, heart rate, altitude e score;
  • tabela de métricas de carga e recuperação;
  • quadro de recordes recentes;
  • mistura de modalidades por distância;
  • distribuição por intensidade;
  • áreas GPS favoritas quando existirem dados de localização.

Esta deve ser a primeira página a consultar quando queres uma leitura rápida mas completa do teu estado atual.

11. Resultados gerais

A página General Results é a visão principal para analisar o período selecionado.

  • KPIs do intervalo filtrado.
  • Comparação dos últimos 30 dias contra os 30 dias anteriores.
  • Estado do treino: equilibrado, carga elevada, potencialmente excessivo ou carga recente baixa.
  • Volume mensal: distância e tempo.
  • Performance mensal e heart rate.
  • Elevação e calorias.
  • Performance por distância e elevação.
  • Contribuição por tipo de atividade.
  • Melhores dias da semana por volume e performance.
  • Indicadores estatísticos.
  • Atividades do último mês.

Esta página é ideal para responder: “Como estou no período escolhido?”

12. Página por atividade

A página Activity Deep Dive permite escolher um tipo de atividade e ver uma análise dedicada com a mesma lógica dos resultados gerais.

Exemplos:

  • Run: distância, pace, performance, HR, elevação, distribuição e último mês.
  • Ride: distância, velocidade, altitude, HR, carga, performance e último mês.
  • Walk/Hike: volume, elevação, tempo e consistência.

No fim da página, tens também os recordes dessa atividade.

13. Estado do treino

As páginas Training Hub, General Results e Activity Deep Dive incluem sinais de estado de treino.

Esta secção indica se o treino recente parece controlado ou se há sinais de carga excessiva.

Como é calculado

  • Compara a carga dos últimos 7 dias com a média semanal das 4 semanas anteriores.
  • Usa training_load quando disponível; se não existir, usa tempo em movimento como fallback.
  • Cruza sinais de performance recente, heart rate médio, intensidade, recovery e fatigue impact.

Estados possíveis

EstadoInterpretação
BalancedA carga recente parece controlada face à tua linha de base.
Elevated loadA carga está produtiva, mas exigente. Convém vigiar recuperação e evitar dias duros seguidos.
Potentially excessiveHá sinais de carga demasiado alta. Considera recuperação, treino leve ou descanso.
Low recent loadA carga recente está abaixo da linha de base. Pode ser recuperação útil, mas menor estímulo de treino.
Needs more historyAinda não há histórico suficiente para comparar bem.
Esta indicação é uma ajuda de análise, não diagnóstico médico. Se houver dor, fadiga persistente ou sintomas anormais, a decisão deve privilegiar descanso e aconselhamento profissional.

14. Recordes e previsões

A página Records & Forecasts mostra recordes pessoais e tendências.

Recordes

  • Maior distância.
  • Maior duração.
  • Maior ganho de elevação.
  • Mais calorias.
  • Maior velocidade média.
  • Melhor pace.
  • Maior heart rate médio e máximo.
  • Melhor performance.
  • Maior training load.

Tendências e previsões

As previsões usam uma regressão linear mensal simples. A linha real aparece sólida, a tendência aparece pontilhada e a previsão aparece tracejada.

Métricas disponíveis: distância, tempo, elevação, pace, velocidade, heart rate, performance e training load.

A previsão é um indicador de direção, não uma garantia. Serve para perceber se a tendência atual aponta para subida, quebra ou estabilização.

15. Mapas e heatmaps

Geo Map

A página Geo Map agrega pontos GPS por células geográficas e mostra:

  • áreas onde passas mais vezes;
  • áreas onde tens melhor performance média;
  • velocidade média por área;
  • heart rate médio por área;
  • tabela das principais zonas.

Heatmaps

A página Heatmaps mostra heatmaps semanais para Run e Ride, com quilómetros por dia da semana e semana ISO.

16. Detalhe de atividade

A página Activities permite escolher uma atividade individual e ver:

  • distância, tempo, velocidade média, pace e performance;
  • intensidade, recuperação e existência de stream GPS;
  • rota no mapa;
  • elevação por distância;
  • pace por distância;
  • velocidade por distância;
  • heart rate por distância, quando disponível;
  • tabela de atividades filtradas.

Alguns ficheiros exportados podem não incluir streams completos. Nesses casos, a app mostra as métricas disponíveis e avisa que não há GPS.

17. Coach e recomendações

A página Coach lista recomendações pendentes geradas com base nas métricas calculadas.

Para recalcular recomendações, usa o botão Refresh Analytics na sidebar ou importa novas atividades.

18. Linha de comando

Para importar um export completo sem abrir a app:

python3 scripts/import_strava_export.py /caminho/export.zip --only-new

Para reprocessar tudo, remove --only-new:

python3 scripts/import_strava_export.py /caminho/export.zip

Depois podes abrir a app e carregar em Refresh Analytics, se precisares recalcular outputs.

19. Updates e manutenção

19.1 Atualizar atividades diariamente

  1. Descarrega as novas atividades/export.
  2. Abre a app.
  3. Faz upload.
  4. Garante que Import only new activities está ativo.
  5. Confirma que o resumo mostra loaded ou skipped.

19.2 Atualizar código local

Se estiveres a receber alterações do Git:

git status
git pull

Depois reinstala dependências se houver mudanças nos requisitos:

pip install -r requirements.txt

19.3 Atualizar schema e analytics

A app chama o inicializador de base ao arrancar. Para recalcular analytics dentro da app, usa:

Refresh Analytics

19.4 Reiniciar a app

Se a app já estiver aberta e alterares código, o Streamlit normalmente recarrega. Para restart limpo:

# parar com Ctrl+C
streamlit run app/streamlit_app.py --server.port 8501

20. Testes e validação

Validação rápida de sintaxe:

python3 -m py_compile app/streamlit_app.py

python3 - <<'PY'

21. Troubleshooting

ProblemaSolução

Porta 8501 ocupada Usa outra porta: streamlit run app/streamlit_app.py --server.port 8502.
Upload não encontra pontos GPS Confirma se o ficheiro contém streams/rota. Alguns exports podem trazer só resumo da atividade.
Atividade aparece duplicada Usa Import only new activities. Para reprocessar, desativa conscientemente essa opção.
Mapa vazio Verifica se há atividades com GPS e se o filtro Only activities with GPS stream não está a excluir tudo.
Base bloqueada ou lenta após import grande Espera o import terminar. Depois reinicia a app. O import já executa otimização da base.
Dados antigos não aparecem Confirma filtros de anos, meses, intervalo de datas e tipos de atividade na sidebar.

22. Boas práticas

  • Usa Import only new activities para atualizações regulares.
  • Mantém a base DuckDB fora do Git.
  • Não guardes ficheiros de atividade pessoais no repositório.
  • Usa .zip para histórico completo e .gpx/.fit/.tcx para atividades isoladas.
  • Depois de uploads grandes, espera sempre a mensagem final.
  • Usa filtros temporais para comparar anos, meses e blocos de treino.
  • Usa Training Hub como ponto de partida diário.
  • Usa Activity Deep Dive para decisões específicas de corrida ou bicicleta.
  • Usa Records & Forecasts para ver direção de evolução, não como previsão absoluta.
  • Faz backup da base DuckDB antes de grandes reimports.
Fluxo ideal: importar novidades, verificar resultados gerais, abrir a atividade principal, rever recordes/tendências e consultar mapas para perceber onde tens melhor performance.
