# Coach Logic

This document explains the coaching recommendation logic.

## Overview

The coach provides personalized training recommendations based on:

- Your recent training load
- Fatigue levels
- Performance trends
- Recovery status
- Training history

### Recommendation Types

- **Rest Day**: Recovery needed
- **Easy Run/Ride**: Low-intensity activity
- **Recovery Run**: Easy activity for active recovery
- **Endurance**: Long, steady activity
- **Intervals**: High-intensity training
- **Long Workout**: Extended duration activity
- **Moderate**: Medium intensity activity
- **Consistency Focus**: Regular training week
