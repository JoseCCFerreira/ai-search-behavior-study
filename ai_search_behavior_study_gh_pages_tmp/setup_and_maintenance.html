Setup, Execução e Manutenção

Sumário

Esta página descreve passo-a-passo como instalar, executar, manter e atualizar o projeto AI Search Behavior Study.

Requisitos

  • Python 3.11+
  • pip
  • Git

Instalação (local)

git clone <URL_DO_REPOSITORIO>
cd ai_search_behavior_study
python3 -m venv .venv
source .venv/bin/activate  # macOS/Linux
pip install -r requirements.txt

Se prefere não criar um virtualenv, instale as dependências num ambiente controlado.

Gerar dados demo (se não tiver dados reais)

python src/data_ingestion/create_demo_data.py

Isto irá popular data/raw/ com ficheiros CSV de exemplo usados pelo pipeline.

Criar base DuckDB e carregar dados

python src/database/create_database.py
python src/database/load_to_duckdb.py

Isto cria data/database/ai_search_behavior.duckdb e popula as tabelas raw e processadas.

Executar a aplicação Streamlit

streamlit run app/streamlit_app.py

A aplicação usa a base DuckDB local. Se não existir, gere os dados demo e carregue-os primeiro.

Substituir dados demo por dados reais

  1. Copie os CSVs reais para as pastas correspondentes em data/raw/:
    • data/raw/google_trends/
    • data/raw/statcounter/ (search_engine e browser)
    • data/raw/similarweb/
    • data/raw/events/
  2. Recrie o banco e carregue os CSVs:
    3. python src/database/create_database.py
python src/database/load_to_duckdb.py

Manutenção e boas práticas

  • Versiona o código via Git; faz commits pequenos e descritivos.
  • Mantém as dependências atualizadas e fixe-as no requirements.txt quando necessário.
  • Não comites dados sensíveis nem ficheiros grandes — usa armazenamento externo para CSVs reais.
  • Usa branches para funcionalidades e pull requests para merges.
  • Automatiza testes com GitHub Actions (já incluído em .github/workflows/python-tests.yml).

Como fazer deploy (resumo)

GitHub Pages (HTML).

  1. Pusha o repositório para GitHub.
  2. Vá a Settings → Pages → Deploy from branch.
  3. Escolha a branch main e a pasta /portfolio_site.

Streamlit Community Cloud

  1. Pusha o repositório para GitHub.
  2. Crie uma nova app em Streamlit Cloud ligada ao repo.
  3. Defina o ficheiro principal para app/streamlit_app.py e confirme requirements.txt.

Problemas comuns

  • Erro de importação `src` nos testes`: executar pytest com PYTHONPATH=..
  • Streamlit não encontrado: ativa o virtualenv e instala as dependências com pip.
  • CSV ausente: verifica os caminhos em src/config.py.
